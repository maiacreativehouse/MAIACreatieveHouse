10 Things to Automate This Week

Ten scheduled automations, each with a prompt you can paste in and go. Pick Claude or ChatGPT, whichever one you already pay for, and let the setup run itself once Monday hits.

This isn't a list of ideas to think about later. It's the order to build them in, the prompts written out in full, and a straight answer on what each tool can and can't do yet. Both platforms now run scheduled tasks on their own servers, so once these are on, they keep running even after you shut your laptop.

By Güneş Ferah Yıldızoğlu
New to this? Set up automation 1 and stop there. Let it run for a week, and once checking it feels like a habit, come back for the rest. Ten at once is how people quit by week two. One at a time is how these stick.

A Few Things Worth Knowing

  • Both Claude and ChatGPT run scheduled tasks on their own servers now, so everything below keeps firing whether or not your laptop is open.
  • Claude's scheduling lives inside Cowork, on the desktop app only. As of this writing, it can create new files in your Drive but can't edit, append to, move, or rename an existing one.
  • ChatGPT is the only one of the two offering a monthly cadence. Claude covers hourly, daily, weekdays and weekly.
  • ChatGPT limits how many tasks you can keep active at once, roughly 5 on a Plus plan and 15 on Pro when this was written. Claude doesn't cap you, at least for now.
  • These tools change fast. Everything here was accurate when this guide was written, but treat the details as a starting point and let rule one below catch anything that's shifted.

Getting It Running

In Claude

You'll need a paid plan and the desktop app, since Cowork doesn't run anywhere else. Open Cowork, start a new task, and type /schedule. Connect Gmail, Calendar, Drive and Slack through Connectors. One setting trips almost everyone up: turn on file creation and code execution first, or Claude has nowhere to save its output. Expect an .xlsx or .docx file to land in Drive, not a native Google Sheet.

In ChatGPT

Any paid plan works. Open the Scheduled tab, paste in your prompt, and choose how often it runs. Connect Gmail, Drive and Calendar. As of this writing, ChatGPT can read and write directly to your Drive, so it can update a spreadsheet you already use. Claude can't do that yet.

Which Tool Handles Which Job

Send anything that updates a file you already keep to ChatGPT. Send anything that needs to touch files sitting on your own computer to Claude, since Cowork can reach your local folders and ChatGPT can't. Everything else runs fine either way, and each automation below tells you which one it needs.

The Four Rules That Make These Survive

Most people abandon this by week three, and it's the same four reasons every time. Every prompt below is built around them.

1

Run it once, by hand, first. Paste the prompt into a regular chat before scheduling it. See what comes back, fix anything off, and only then set it live. An untested prompt on a schedule just means thirty days of getting it wrong on repeat.

2

Give it permission to say nothing. A task that only speaks up when something's actually worth flagging is one you'll keep reading. One that reports in every single day, empty or not, is one you'll mute by Thursday.

3

It forgets everything between runs. There's no memory carried from one run to the next, so it can't reference "like I said yesterday." Every run has to reconstruct the full picture from your calendar, inbox and files, which is exactly why each prompt tells it where to look, every time.

4

Put an expiration date on it. If you haven't opened what a task sends you in five runs straight, that's your answer: turn it off. You'll free up a slot for something you'll actually read.
